# 考研英语词汇训练营（Web/PWA MVP）

这是一个纯前端实现的考研英语单词学习应用原型，覆盖学习、拼写、练习、复习、统计五大模块，并支持 PWA 离线使用。

## 已实现功能

- 多模块导航：单词学习 / 拼写训练 / 题目训练 / 检查复习 / 数据统计
- 单词卡片：正反面切换、发音、收藏、熟练度标记（陌生/模糊/熟悉/掌握）
- 拼写训练：看中文写英文 + 提示 + 自动判错
- 题目训练：释义选择、句子选词两种题型
- 复习系统：错词本 + 简化艾宾浩斯间隔复习（按熟练度设定复习间隔）
- 学习数据：连续打卡、掌握率、错词数量、词库规模
- 每日计划：30/50/100 词
- 深色模式
- 本地持久化：localStorage 保存进度

## 词库说明

- 内置基础考研词条字段：英文、音标、中文释义、词性、搭配、例句、重要度。
- 为满足大词量演示，前端生成了 12,000 条可训练词项（基础词条扩展生成）。
- 可后续替换为权威考研词库接口/文件。

## 运行方式

```bash
python3 -m http.server 8000
```

访问 <http://localhost:8000>。

## 作为 App 使用

- Android Chrome / iOS Safari 打开后可「添加到主屏幕」。
- 已注册 Service Worker，支持离线访问最近缓存。
